概要・強み

ABOUT ME
現場の課題を紐解き、
「仕組み」と「自動化」で
業務を前に進める。

教育機関でのデータ集計・RPA業務自動化から始まり、医療機関でのSQLを用いたデータ抽出・管理、そしてITインフラ支援・企業内システム管理まで、一貫して「現場で実際に使われるITの仕組みづくり」に携わってきました。

Windows 11移行やActive Directory環境での端末・アカウント運用といったインフラ基盤の知識と、Excel / VBA / WinActor / PowerShell / Pythonを活用した業務効率化の両軸を強みとしています。現在はネットワーク・Linux領域のさらなる専門性向上に向け、CCNA・LPICの習得にも取り組んでいます。
